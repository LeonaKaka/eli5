02 · Research Assistant v6.2

现在真的建一个 MCP Server。
Client 通过协议发现它，而不是 import 函数表。

这一课直接使用当前 Python SDK v2：`MCPServer` 暴露 capability，`Client(mcp)` 走官方 in-process MCP path。你会实际看到 `tools/list → tools/call → resources/read → prompts/get` 的不同职责。

1

现在的 Python SDK 高层 API 很小

from mcp.server import MCPServer
from mcp import Client

mcp = MCPServer("Research Assistant Capabilities")

@mcp.tool()
def search_papers(query: str, limit: int = 3):
    ...

@mcp.resource("research://catalog")
def catalog():
    ...

@mcp.prompt()
def compare_papers(left_id: str, right_id: str):
    ...

函数名/Docstring/type hints 会生成能力名、description、tool input schema。你不需要自己手写 `tools/list` JSON-RPC handler。

2

Research MCP Server 的真实 inventory

3
`@mcp.tool()`：schema 是协议 contract，不是 Python 函数注释
@mcp.tool()
def search_papers(
    query: str,
    limit: int = 3,
) -> list[dict[str, str]]:
    """Search the teaching paper catalog by title, topic or summary."""
    ...
Client 调 `tools/list` 后得到的不只是名字，还拿到模型可见的 description 和 JSON Schema。`query: str`、`limit: int` 会真正限制“模型应该构造什么 arguments”。
但 schema 只解决输入形状。它不替你解决 tenant 权限、side-effect approval、quota、idempotency。
4
Resource 和 Tool 在 wire 上就是不同 verb
Tool discovery`tools/list` → search_papers + inputSchema
Tool execution`tools/call` → name + arguments → result
Resource discovery`resources/list` / `resources/templates/list`
Resource read`resources/read` → `research://catalog`
Prompt discovery`prompts/list`
Prompt render`prompts/get` → rendered user message(s)
5
Resource Template：一个函数服务很多地址
@mcp.resource(
  "research://paper/{paper_id}",
  mime_type="application/json",
)
def research_paper(paper_id: str):
    ...
research://paper/rfim-domain-wall
→
paper_id=rfim-domain-wall
→
JSON context
这跟 `search_papers(query)` 的意义完全不同：Template 已经有一个可寻址 URI pattern；Host 知道具体 id 后可以精确读取。
6
Prompt 返回的是 messages，不是“服务器替模型回答”
@mcp.prompt()
def compare_papers(left_id: str, right_id: str) -> str:
    return (
      "Compare ... "
      f"Read research://paper/{left_id} ..."
    )
`prompts/get` 最终得到 prompt messages。Host 可以把这些 messages 送给自己的模型；MCP Server 本身并没有因此变成 Agent/LLM。
7
Interactive · Client connection topology
这三种 transport 改变的是 Client ↔ Server 怎么连，不应该改变 `search_papers` 的业务语义。第 03 课会专门展开。
8
为什么测试优先 `Client(mcp)`？
async with Client(mcp) as client:
    tools = await client.list_tools()
    result = await client.call_tool(
        "search_papers",
        {"query": "domain wall"},
    )
它不像 `search_papers("domain wall")` 那样绕过协议层；Client 仍然经历 MCP capability surface、tool call result、resource/prompt result 类型，只是省掉 subprocess/network 的不稳定因素。这正适合 unit/integration boundary。
