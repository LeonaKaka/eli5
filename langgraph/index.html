Why

不是“LangChain 还是 LangGraph 二选一”

它们处在不同抽象层。
Model SDK / LangChain Models固定调用、结构化输出、简单函数调用
LangChain create_agent标准模型 ↔ Tools 循环 + middleware
LangGraph StateGraph显式 State / routing / loops / persistence / interrupts
App Infrastructuretenant / auth / queue / lease / side-effect contracts
重点：`create_agent` 本身建立在 LangGraph runtime 上；custom `StateGraph` 是需要更强控制时往下走一层，而不是另一个竞争框架。
