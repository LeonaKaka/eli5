模型不是住在 Python 里。
它通常是网络另一端的服务。

你写 client.responses.create(...) 时，真正发生的是：你的程序把请求序列化、经过 HTTPS 发到模型服务，服务做推理，再把一个结构化 response 发回来。这一课把整条链拆开。

1

先拆掉第一个错觉：“SDK 在本地跑模型”

SDK 只是帮你更方便地构造 HTTP 请求和解析响应。
你的 Python

组装 model、input、tools、schema、timeout 等参数。

→
远程 Model Service

鉴权 → 排队 → 推理 → 生成 output → usage。

核心直觉：调用 LLM 更像“调用数据库/支付 API”，不是调用本地 math.sqrt()。因此网络、认证、超时、限流、计费、版本变化都会进入工程设计。

失败位置典型症状不是谁的锅
请求构造字段/类型/schema 错不是模型能力问题
网络/认证timeout、401、429模型甚至可能没开始推理
模型输出回答差、格式不理想这才更多涉及模型/上下文/参数
解析/业务层你取错 response 字段模型已经正常返回
3

REST 和 SDK，其实是同一件事的两种皮肤

面试不要求你手写 curl，但要知道 SDK 没有魔法。
REST / HTTP
POST /v1/responses
Authorization: Bearer ...
Content-Type: application/json

{
  "model": "...",
  "input": "解释 RAG"
}

更接近协议本身，容易理解网络层。

Python SDK
client.responses.create(
    model="...",
    input="解释 RAG",
)

负责 URL、headers、序列化、response model 等样板代码。

工程判断：日常开发优先官方 SDK；调试协议、做自定义网关、理解错误时要能退回 HTTP 层思考。

Interactive：亲手拼一个请求

这个实验不会真的访问模型，也不会要求 API key；只展示“你的 Python 最终要表达什么”。

后面第 06/07 课会分别把 Structured Output 与 Tool Calling 彻底拆开；这里先看它们都只是 request 上新增的一组能力声明。

5

不要只拿“答案字符串”：Response 本身也很重要

可靠产品需要知道这次调用是谁、是否完成、用了多少 token、是否产生 tool call。
response = client.responses.create(
    model=MODEL,
    input="解释 RAG",
)

print(response.id)
print(response.status)
print(response.output_text)
print(response.usage)
output

不一定只有 text；以后可能有结构化数据、tool call、其他 modality。

usage

输入/输出/cached token 等计量信息，是成本与性能观测的基础。

id / status

用于日志、trace、问题定位和关联一次具体调用。

坏习惯：业务层到处直接 print(response.output_text)，但从不保存 latency、usage、model、request id。出质量/成本问题时几乎没法复盘。
6

API Key 是服务器秘密，不是前端配置

GitHub Pages 是纯前端，所以这个课程站永远不会放真实模型 key。
❌ 浏览器 JS
const apiKey = "sk-..."

任何访问网页的人都能拿到。就算“混淆”也不是秘密。

✅ 后端环境变量
client = OpenAI()
# key 从环境变量读取

浏览器只调用你自己的后端；真正 key 留在服务器侧。

这也是为什么后面 FastAPI 能力仍然重要：真正产品通常是 Browser → Your Backend → Model Provider，而不是 Browser 直接拿私人 API key 调模型。
7

Provider abstraction：别让业务代码绑死一个 SDK

不是为了炫技，而是把供应商细节和业务语义分开。
from typing import Protocol

class LLMClient(Protocol):
    async def generate(self, prompt: str) -> "LLMResult": ...

class LLMResult:
    text: str
    model: str
    input_tokens: int
    output_tokens: int
    request_id: str | None
