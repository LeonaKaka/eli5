哪些东西是“产品事实”？

RunStoretenant、Run status、revision、cancel、approval request、checkpoint reference。客户端看到的产品状态以这里为准。
LangGraph checkpointerGraph StateSnapshot、next node、interrupt continuation。它知道“图执行到哪”，但不是用户权限数据库。
Queue / Worker负责至少一次 delivery、claim、lease、重试调度。Queue message 不是 Run 本身。
Event log / SSE是客户端投影和增量通知，不是 authoritative Run state。丢 retention 后应重新 GET Run。

Docker 能启动 ≠ Production Ready
docker run research-assistant

如果里面仍然是：
InMemoryRunStore
InMemoryRunQueue
InMemorySaver
InMemoryRunEventStore
InMemoryIdempotencyStore
DemoTokenAuthenticator

→ 单副本重启就丢事实
→ 两个副本之间互相看不到状态
→ approval / retry / SSE 语义失真
→ 不能因为“容器跑起来了”就叫生产
v6.0 的 production profile gate 会直接拒绝这一组合。Docker 主线下一步的任务，就是逐个替换这些 process-local adapter。

  ↓
Worker claim r8
  ↓

注意每一层都只承担自己的证明：Bearer 证明 identity/permission，If-Match 证明客户端状态没过期，Idempotency-Key 证明同一逻辑 command 不重复执行，checkpoint 证明 Graph 能继续。
