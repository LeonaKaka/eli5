Agent Engineering · 2 / 10 起步

Agent 不是“LLM + 一堆 Tools”。
关键是：谁决定下一步做什么，以及什么时候停。

Research Assistant v3.0 已经有 Tool、RAG、Citation 和 Eval。Agent 线从这里继续：让系统在每一步根据当前 State 和 Observation 自己选择动作，但同时用应用侧状态机、预算、审批和 Eval 把这种自主性约束住。
